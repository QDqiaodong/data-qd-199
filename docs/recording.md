# 录音切片配准与采集块回收契约：RecordingSnapshot

`score_spans.recording` 在旧谱面处理、演奏窗、语料发布、对账、终端入口与
CLI 之外，提供一套归档端与采集端共用的本地接口：把谱面时间轴上的切片单
经对时锚点换算到 PCM 块目录的采样点轴，判定每个切片单的交付状态、产出
就绪清单，并决定哪些不可变 PCM 块当前可以整块回收。纯 Python、只依赖
标准库，**只处理目录与结构化数据，不读写任何 PCM 内容**，不管理跨进程
状态或对象存储。

```python
from score_spans.recording import RecordingSnapshot, plan_snapshot, read_manifest

snapshot = RecordingSnapshot(snap)   # 一次解析、建立索引
plan = snapshot.plan()               # 全局规划：每单状态 + 可回收块
manifest = snapshot.manifest('A')    # 按单号读取一份就绪清单
# 一次性便捷入口（各自重新解析快照）：
plan = plan_snapshot(snap)
manifest = read_manifest(snap, 'A')
```

同一份输入的规划与按单读取必须基于同一快照：需要两者时显式构建一个
`RecordingSnapshot` 复用。调用方串行应用回收——本模块给出当前快照下的
判定，不保存任何跨快照状态。

## 快照形状

快照是一个对象，恰有六个字段：

| 字段 | 含义 |
| --- | --- |
| `recording_id` | 录音 ID，走仓库标识符规则 `[A-Za-z0-9_:-]{1,64}` |
| `score` | 源谱，沿用现有 `measures`/`events`/`transpose` 模型，源谱顺序、精确四分音符时值、移调后发音链，不展开反复 |
| `anchors` | 对时锚点数组，1..2000 项 |
| `blocks` | 当前可读块目录，0..20000 项 |
| `seal` | 封口采样点 B，0..2^53−1 整数（布尔值拒绝） |
| `tickets` | 切片单数组，0..10000 项 |

### 源谱准入

沿用对账/终端入口的严格口径：有越界（`overrun`）、同声部重叠
（`overlap`）或无效延音（`invalid_tie`）的谱拒绝用于切片；留白（gap）、
纯休止与空事件表允许，此时清单的标签数组为空，但只要录音覆盖完整，
纯休止切片仍可交付。

### 锚点

每项恰有 `position`（`[分子, 分母]` 非负有理数，分子 0..10^9，分母
1..10^6，布尔值拒绝）与 `sample`（0..2^53−1 整数）。约束：

* 首项必须是 `([0,1], 0)`；
* 位置列与采样点列都严格递增；
* 锚点位置不可超出全谱末尾；
* 相邻锚点之间用精确直线换算；锚点自身可用，最后一个锚点之外**不可
  外推**（落到末锚点之外的切片端即等锚点）。

### 块目录

每行恰有 `id`（仓库标识符，全目录唯一）、`start`、`end`（0..2^53−1
整数，`end > start`，正长度）。块可相邻但不能相交；目录数组顺序不
代表时间，内部统一按起点排序。块只可整块回收。

封口点 `B` 表示不会再补交任何覆盖 `B` 以下采样点的块，**不**表示那些
采样点曾被录到；已有块允许跨过封口点。

### 切片单

每单恰有 `id`（唯一）、`start`、`end`（谱面位置对）与 `closed`（布尔）。
区间是合法半开区间：正长度且整体落在全谱内。录音开始时单号与区间全部
确定。`closed=true` 表示归档端已脱离原块独立保管素材，或调用方已明确
放弃该单；结束标记只会从否变是，跨快照的这些约束由调用方保证。

任何形状或不变量非法都抛 `InvalidSnapshot`（也是 `ValueError`），不
交付任何部分结果。

## 半开边界与精确换算

切片 `[a,b)` 两端都能换算时，精确得到 `F(a)`、`F(b)`（`Fraction`），
实际取整数采样点满足 `F(a) ≤ i < F(b)`，即整数半开区间
`[ceil(F(a)), ceil(F(b)))`。两端分别按各自所在的锚点段换算，**不能用
切片两端拟合一条直线**；向上取整精确完成，不经过浮点。相邻切片在
分数边界处因此既不重取也不漏取。

## 规划：plan()

返回 `{'recording_id', 'tickets', 'reclaimable_blocks'}`。`tickets`
按单号升序，每行含 `id` 与 `status`，状态共五种：

| status | 含义 | 附带字段 |
| --- | --- | --- |
| `closed` | 交接已结束（或已放弃），不再交付、不占用块 | — |
| `await_anchor` | 右端尚不能换算（含两端都待校准），等后续锚点 | — |
| `await_block` | 区间可换算，目录仍缺采样点且缺口都还在封口之外 | `sample_start`/`sample_end` |
| `ready` | 目录对区间覆盖完整，不要求等封口 | `sample_start`/`sample_end` |
| `undeliverable` | 永久不可交付，附 `reason` | `sample_start`/`sample_end`、`reason` |

判定顺序（未结束单）：

1. 右端超过最后锚点位置 → `await_anchor`；
2. 否则换算两端；`ceil(F(a)) == ceil(F(b))`（区间没有任何采样点）→
   `undeliverable`，`reason="empty_interval"`；
3. 否则若封口以下存在任何未覆盖采样点（空洞落在
   `[ceil(F(a)), min(ceil(F(b)), B))` 内）→ `undeliverable`，
   `reason="sealed_gap"`，不拿空洞当静音；
4. 否则目录仍缺采样点 → `await_block`；
5. 否则 `ready`。目录完整即就绪，不要求等封口。

`reclaimable_blocks` 是当前快照下所有符合回收规则的块 ID，按 ID 升序。

### 块保留与回收规则

只有**完全位于封口内**（块尾 `end <= B`）且**不再有任何未结束切片可能
需要**的块才能回收：

* `ready` 单也要保留原块，直到归档交接结束（`closed`）；
* `await_block` 单保留整个已确定采样区间碰到的现存块；
* `undeliverable` 与 `closed` 单不占用任何块；
* `await_anchor` 单必须为后续补锚点保留素材，不能因产不出清单就当作
  无依赖：左端已可换算时从 `ceil(F(a))` 起保留；左端也未知时从最后
  一个锚点的采样点加一开始保留。此时上界未知，保留所有碰到该尾区间
  的现存块。锚点补齐后按新的实际范围重新决定。

“碰到”指与保留区间有正长度交集；区间刚好相接（块尾恰好等于区间起点）
不算占用。同一块被多单共用时，等最后一个依赖消失才回收。块可以跨过
封口点，这样的块即使无依赖也不回收（只能整块回收）。规划不能用
“永不回收”规避判断：满足条件的块必须全部返回。

规划只产出状态与区间，**不预生成任何按单清单或标签**；块占用经块下标
差分数组汇总，复杂度约 O(T log N + N)，不逐单扫描全部块，也不展开
逐采样点数据。

## 按单读取：manifest(ticket_id)

未知单号抛 `UnknownTicket`；单号存在但当前不是 `ready` 抛
`TicketNotReady`，均不吐出半份清单。就绪清单字段：

| 字段 | 含义 |
| --- | --- |
| `recording_id` | 录音 ID |
| `ticket_id` | 切片单号 |
| `sample_start` / `sample_end` | 实际整数采样区间 `[lo, hi)` |
| `blocks` | 按采样顺序拼接的块与块内半开偏移，见下 |
| `labels` | 与切片实际相交的发音链标签，见下 |

每个块行含 `id`、`offset_start`、`offset_end`：该块贡献的样本在块内的
半开字节偏移（相对块起点的采样点数），即取块内
`[offset_start, offset_end)`；只交付与切片相交的部分，不交付区间外
数据。块目录乱序不影响这里的采样顺序。

### 标签

先在**谱面轴**上裁剪每条发音链（合法延音合并后的整条链，含整组移调后
音高与按时间排列的源事件 ID），再把裁剪两端按各自所在锚点段精确换算，
使用与取样相同的向上取整；裁剪后取不到任何采样点（两端取整相等）的
标签省略。每个标签含：

| 字段 | 含义 |
| --- | --- |
| `voice` | 声部 |
| `pitches` | 整组移调后音高（数组） |
| `events` | 整条链按时间排列的源事件 ID |
| `relative_start` / `relative_end` | 相对交付区间开头 `lo` 的整数起止采样点（半开） |
| `contains_onset` | 本切片是否包含该链的**真正起音**（链首落在切片内） |

裁剪进来的延音不是新起音：即便它从切片第一个采样点开始，
`contains_onset` 也为 `false`。纯休止切片的标签数组为空。标签按
`(换算后起点采样点, 声部, 链首事件 ID)` 排序；清单块按采样顺序、规划
行与回收 ID 按 ID 排序——重排块目录、切片单或源事件都不改变结果。
整个返回值只含 JSON 原生类型，可直接 `json.dumps`。

## 错误类型

| 类型 | code | 含义 |
| --- | --- | --- |
| `InvalidSnapshot` | `invalid_snapshot` | 快照形状或不变量非法（也是 `ValueError`） |
| `UnknownTicket` | `unknown_ticket` | 清单读取时单号不存在 |
| `TicketNotReady` | `ticket_not_ready` | 单号存在但切片单当前非就绪 |

## 测试

在本仓根目录（已安装本包或把 `src` 加入 `sys.path`）：

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

`tests/test_recording.py` 覆盖：

1. 验收例 1：锚点 `(0,0)/(1,3)/(2,8)`、块 X/Y/Z/W、切片 B/A 的状态、
   取块、回收（仅 W）、分数边界无重取漏取、裁入延音不标起音且相对
   位置按分段换算（不能两端拟合直线）；
2. 验收例 2：缺末锚点时 A 等锚点且 Y/Z/W 不回收；B 结束后 X 可回收；
   删 X 补锚点后 A 清单与例 1 字节一致且 W 才回收；删 Z 后封口 4 等
   块（保留 Y）与封口 8 不可交付（放开 Y，B 仍就绪、X 仍保留）；
3. 跨封口块不回收、多单共享块等最后依赖、左端也待校准的尾区间保留、
   刚好相接不占用、空区间不可交付、纯休止可交付、标签省略与稳定顺序；
4. 规模用例：20000 块、10000 个大量相互重叠切片、2000 锚点，先全局
   规划再读一份就绪清单，规划不预生成清单、不逐单扫块、不展开采样点；
5. 非法输入矩阵、未知/非就绪单拒绝与旧入口回归。

## 边界

本模块不改变 `process` / `process_window` / 语料发布 / 对账 / 终端 /
CLI 的任何行为；不读写 PCM、不持久化文件、不处理并发与对象存储。
调用方负责快照的一致性、按规划结果串行删除块条目，以及在同一快照上
规划与读取。
